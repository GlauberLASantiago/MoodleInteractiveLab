Moodle Interactive Lab 🧪

O Moodle Interactive Lab é uma ferramenta web simplificada projetada para ajudar professores a criar recursos visuais modernos e interativos para o Moodle sem a necessidade de conhecimentos em programação ou design.

🎯 Objetivo

Transformar a experiência de aprendizagem no Moodle (AVA), permitindo que docentes gerem trechos de código HTML/CSS prontos para copiar e colar, garantindo uma interface profissional, responsiva e engajadora para os estudantes.

✨ Recursos Disponíveis

Sanfona (Accordion): Organize conteúdos longos ou FAQs.

Caixas de Alerta: Destaque avisos, prazos e dicas importantes.

Cartões de Conteúdo: Apresente módulos e links externos com visual moderno.

Passo a Passo: Crie roteiros de estudo e sequências didáticas claras.

Flashcards (Flipcards): Ideal para memorização de conceitos e termos técnicos.

Tabelas Comparativas: Diferencie softwares, teorias ou abordagens lado a lado.

🚀 Como Usar

Acesse a ferramenta (via GitHub Pages ou localmente).

Selecione o recurso desejado na barra lateral.

Preencha os campos de texto e escolha as cores de sua preferência.

Acompanhe o resultado em tempo real na área de Pré-visualização.

Clique em "Copiar Código Moodle".

No Moodle, ative a edição, adicione um Rótulo ou Página, clique no ícone de código (</>) no editor de texto e cole o conteúdo.

🛠️ Tecnologias Utilizadas

HTML5/CSS3

Tailwind CSS: Para estilização moderna e responsiva.

Vanilla JavaScript: Lógica de manipulação de templates e interface.

Lucide Icons: Conjunto de ícones minimalistas.
